# KPI Atlas

ブラウザで使える月間KPIツリーです。指標を階層化し、実績・月間目標・今日の目安をカードで見比べられます。

**[ブラウザで使う](https://seimakoizumi.github.io/kpi-atlas/)**

1. 初期状態は「主要KPI」1件です。先に試したいときは「サンプルを見る」で架空のツリーを編集できます。「自分のツリーに戻る」とサンプルの編集内容はリセットされます。
2. KPIを選択して「KPIを追加」か「タスクを追加」を押すと、そのKPIの下にカードを作れます。タスクはカードのチェックボックスで完了にできます。カードを選択して Enter を押すと、同じ親の下で選択したカードの直後に同じ種類のカードを追加します。
3. 線上の「+%」から歩留まりを入れると、左の月間目標を歩留まりで割って右の目標を計算します。件数は切り上げます。必要に応じて目標を手入力できます。
4. 実績は手入力、子KPIの合算、集計APIからの取得に対応しています。
5. Ctrl+Z で元に戻し、Ctrl+Y でやり直せます。Mac は ⌘Z／⌘⇧Z です。並べ替えや親子関係の変更を戻すときは「移動モード」をオンにします。

ログインは不要です。自分のツリーと連携先URLは、使っているブラウザのプロファイルに保存します。端末やプロファイルごとに別のツリーになります。同じ端末で同じブラウザプロファイルを共有する人は、同じツリーを開けます。サイトデータを消すと保存したツリーも消えます。

## 配色・共有

ヘッダーのパレットから、メイン・サブ・アクセントの3色を変更できます。名前付きの20テーマも選べます。

「共有」から現在表示している月のコピーで共同編集を始めます。作成者はChatGPTでログインし、閲覧用・編集用の招待リンクを発行・無効化できます。コピーにはカードと取得済みの実績が入り、外部APIの接続設定は元のツリーで管理します。

共有ツリーのオーナーは、KPIやタスクを選んで「Slackへ送る」からチャンネルとメンション先を指定できます。初回は対象のSlackワークスペースのBotトークンを接続してください。

## ローカルで起動

Node.js 24を使います。

```sh
npm ci
npm run dev
```

公開用の静的ファイルは `npm run build` で `dist/` に生成されます。

## 集計APIをつなぐ

「データ連携」で、認証不要の読み取り専用HTTPSエンドポイントを登録します。APIはブラウザからのリクエストをCORSで許可し、`GET ?month=2026-11` に次のようなJSONを返します。連携先は集計値だけを返すようにしてください。

```json
{
  "metrics": { "completed": 12, "channel.a": 5 },
  "channels": [{ "key": "channel.a", "label": "チャネルA" }]
}
```

「今すぐ同期」でキーを取得し、対象のKPIで「外部API連携」を選び、そのキーを設定します。`channels` は任意です。親KPIの「連携先の内訳KPIを自動追加」をオンにすると、内訳のカードも作成します。
